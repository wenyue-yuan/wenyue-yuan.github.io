# Wenyue Yuan — Academic Homepage

A responsive single-page academic homepage, designed for GitHub Pages.

## Publish on GitHub Pages

1. Sign in to GitHub as `wenyue-yuan`.
2. Create a **public** repository named exactly `wenyue-yuan.github.io`.
3. Upload `index.html` and the `assets` folder to the root of the repository.
4. In repository **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)` and save, if Pages is not already enabled.
5. Visit `https://wenyue-yuan.github.io/` after deployment.

## Edit content

Open `index.html` in any text editor. Change the profile text, research interests, news, publications, and projects. Replace `assets/profile.jpg` to change the portrait.

**Before publishing:** Confirm current position/affiliation, whether to show a public contact email, and publication details. This draft is based on an uploaded CV and does not assume a current appointment.
